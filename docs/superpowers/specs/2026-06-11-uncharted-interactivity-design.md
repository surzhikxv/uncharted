Дата: 2026-06-11. Согласовано с заказчиком в брейншторме (визуальный компаньон + терминал).

## Контекст

Десктоп 1920px (`.page` в `index.html` + `styles.css`) свёрстан pixel-perfect по Figma
(файл `0oOzxMla9AEFWsIQ8FgOCv`, фрейм `521:581`), масштабируется `zoom`-ом. Мобильное
дерево `.m` + `mobile.css` — **в этой итерации не трогаем вообще** (заказчику текущая
мобильная версия не нравится, переделка отложена; ломать нельзя). Эталон —
`reference/frame-full.png`, дифф — `node /tmp/pngtools/finediff.js`, скриншоты —
Playwright (`/tmp/pwtool/`) и `./shot.sh`.

Часть фотослоёв запечена кусками рендера Figma в `public/images/render/` — где это
мешает интерактиву, аккуратно заменяем живыми слоями.

## Архитектура (подход 1 — согласован)

Без зависимостей и CDN. Новые файлы:

- **`app.js`** — конфиг ссылок `LINKS` (одно место для всех URL); модалка КУПИТЬ;
  плавный скролл навигации; карусель (состояние, стрелки, смена текстов);
  scroll-reveal через IntersectionObserver + CSS-классы; параллакс через rAF + lerp,
  запись в CSS-переменные.
- **`shaders.js`** — мини-движок WebGL2 (~400 строк): компиляция программ, загрузка
  текстур, общий rAF-цикл, пауза канвасов вне вьюпорта, DPR cap 1.5. Три шейдера:
  1) фотоокно: панорама + маска растворения в кремовый по краям + uv-параллакс от
     скролла + subtle heat-haze (simplex noise);
  2) liquid-морф карусели: две текстуры, displacement-нойз, progress-униформа,
     тягучая кривая;
  3) хиро: едва заметное тепловое марево + плёночное зерно поверх фото (низкая
     амплитуда, чтобы не спорить со статикой).
- **`anim.css`** — стили модалки, hover-состояний, reveal-классов, стрелок карусели.

Фолбэки: нет WebGL → статичные изображения с CSS-масками; `prefers-reduced-motion` →
все анимации и шейдеры отключены, контент статичен и полностью читаем.

Внимание: `.page` использует `zoom` — модалку рендерить как `position: fixed` элемент
ВНЕ `.page` (прямой ребёнок `body`), чтобы не зависеть от zoom-масштаба.

WebGL-текстуры не грузятся с `file://` (CORS) — для разработки и скриншотов поднимать
локальный сервер (`python3 -m http.server`) либо Chromium с
`--allow-file-access-from-files`.

## Компоненты

### 1. Ссылки и модалка
- Существующие `<p>`/`<div>` превращаются в кликабельные без изменения геометрии
  (тот же класс/позиция; `<a>` внутри или обработчик + `cursor:pointer`).
  Пиксель-дифф статики должен остаться чистым.
- Модалка: оверлей затемнения, карточка в стиле бренда (#FAF5F1, Tenor Sans,
  терракота #C35B3F), 4 строки магазинов с иконками из `public/images/icon-*.svg`,
  target=_blank rel=noopener. Закрытие: крестик, клик мимо, Esc. Без библиотек.
- Лого → плавный скролл наверх. Соцсети/почта/магазины футера — прямые ссылки.

### 2. Фотоокно (замена плиты)

- Вместо него `<canvas class="abs photoband">` той же геометрии (0, 1392, 1920×378).

- Сверить текст n623 с актуальным макетом (заказчик показал скрин с обновлённой
  формулировкой «ВЫСОКОЕ КАЧЕСТВО ОТДУШЕК ПРЯМИКОМ ИЗ ЕВРОПЕЙСКИХ ПАРФЮМЕРНЫХ
  ДОМОВ») — обновить, если в Figma новее.
- `<canvas>` на месте n625 (733, 5701, 442×1083). Морф ~1.4s, easing тягучий.
- Стрелки: тонкие терракотовые шевроны слева/справа от флакона, hover — сдвиг 4px,
  фокус-стили для клавиатуры. Зацикленный список.
- Тексты n622 (подпись) и n624 (описание) меняются live-DOM с кроссфейдом
  (CSS opacity/translate, синхронно с морфом). Если в Figma у ароматов есть свои
  фоновые акценты — не переносить (вне скоупа), меняются только флакон и тексты.
- Фолбэк без WebGL: мгновенная смена картинки `<img>` + кроссфейд.

### 4. Перебейк скалы
- Экспорт ноды 521:690 из Figma (figma MCP `download_figma_images`, scale под
  текущий размер 557×1102) — слой скалы без текста.
- Заменить `public/images/render/rock-690.png`. Позицию/размер в CSS не менять.
- Проверка: в зоне слова буквы единообразно живые; дифф с эталоном вне зоны букв
  не ухудшился.

### 5. Анимации
- Reveal-классы: `[data-reveal]` на текстах интро, заголовках, карточках (stagger
  120ms), лейблах диаграмм, тезисах, блоках футера. IntersectionObserver, порог 0.2,
  один раз (без повторного скрытия). Тайминг ~800ms, cubic-bezier(0.22, 1, 0.36, 1).
- Параллакс: planet-731 (±20px), rock-690 (±12px), pump-697 (±10px), hero-right
  (±8px), фотоокно (внутри шейдера). rAF + lerp (k≈0.08), transform: translate3d.
- Гигантский UNCHARTED: split на `<span>` по буквам (aria-label на контейнере,
  span'ы aria-hidden), проявление по букве (opacity+translateY, stagger 60ms).
- Хиро при загрузке: лого → нав → текст → кнопка, fade-up stagger 150ms.
- Hover: кнопки — лёгкое затемнение фона + letter-spacing +0.02em; карточки
  каталога — подъём 6px + мягкая тень; ссылки футера — терракотовый сдвиг цвета.
- Канвас-эффект хиро держать ниже текстов хиро по z-order (не блюрить текст).

## Верификация (после каждого шага)

1. `./shot.sh` / Playwright скрин 1920px → `node /tmp/pngtools/finediff.js` против
   `reference/frame-full.png`. Допустимые отличия только в намеренно изменённых
   зонах (плита y1392–1770; зона впечённых «UN» у скалы). Анимации для диффа
   отключать (reduced-motion / снимок до старта анимаций — снимать с
   `prefers-reduced-motion: reduce`).
2. Мобильная версия: поэкранные скрины ≤768px (`/tmp/pwtool/mscroll.js`) — ничего
   не изменилось и не сломалось.
3. Интерактив: Playwright-прогон — клики по навигации скроллят, модалка
   открывается/закрывается, стрелки листают, ссылки имеют корректные href.
4. Производительность: канвасы паузятся вне вьюпорта (проверить rAF-счётчик),
   страница без WebGL и с reduced-motion полностью функциональна.
